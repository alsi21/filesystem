• How do we structure and find the information on disk?
    Figure out where and how file header is saved.
    
    "The file system we will implement should be organized as a file allocation table (linked allocation with an index table, see Sections 4.3 and 4.5.1 in [1])"

    1 block is 4096 bytes

    Root -> block 0
    FAT -> block 1

    2 bytes per FAT entry
    FAT entry corresponds to disk block
    2048 blocks per partition -> 8MB partition



• In which blocks do we store the information of a particular file?

    According to FAT, as seen page 3 of instructions

• How do we keep track of which blocks free / available and which are allocated?

    We do this in the FAT presumably, see page 3
